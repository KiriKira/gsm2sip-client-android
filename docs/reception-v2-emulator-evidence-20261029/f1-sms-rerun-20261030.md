# F1 baseline SMS rerun — 2026-10-30

This is a sanitized supplement to `f1-preflight-20261030.md`. It records one real emulator SMS path after the Madoka HTTPS relay registration preflight was corrected. The test used the exact-main GW/H1 debug APKs and isolated Node C owner described in the validation report; no API-created event or synthetic push was used.

## Evidence

- At `2026-10-30T14:53:45Z`, the GW emulator accepted one `adb emu sms send` command. The command exited `0` and returned `OK`; marker: `R1F1SMS1030`.
- GW logcat recorded one `SmsReceiver` event: `SMS received and journaled (parts=1, sim=known, sequence=1)`.
- Node C SQL recorded one row for the marker: `direction=inbound`, `status=received`, `created_at=2026-10-30T14:53:45Z`.
- The Madoka push endpoint was HTTPS. Before injection, its event cursor was `0`; after delivery it was `1`, with `failures=0` and `call_failures=0`. Effective reception protocol was `1` (`device_reception` absent, so server default); `delivered_at` advanced in the same event window.
- H1 logcat recorded `HostPush: received priority=1`. The exact-main Madoka source logs only priority/original priority, so it does not print wire or kind. The received `type=sync` callback is accepted only for wire `1` (missing `v` or `v=1`); the server selected its legacy version-1 path, and the Kyubey contract defaults an omitted version to `1`.
- Android UI hierarchy on H1's SMS tab contained `R1F1SMS1030`. NotificationManager held active Madoka notifications on the inbound-SMS channel.
- The local Wrangler auto-debug log contained no inbound wake record or outbound FCM request/response record in this event window. This does not contradict delivery: the server advanced the cursor only after its relay `Wake` request succeeded, and H1 then received the FCM callback and displayed the SMS. The Wrangler record cannot independently provide this event's TTL/urgency fields.

Raw logcat, database access material, notification dump, UI hierarchy, relay endpoint, tokens, and phone identifiers remain on the private test host and are not committed. The evidence above reports only sanitized event facts.
