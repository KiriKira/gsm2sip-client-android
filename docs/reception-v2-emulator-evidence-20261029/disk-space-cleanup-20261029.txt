H3 startup result
=================

After cleanup, the API 34 no-Google-Play H3 AVD started successfully from its
existing userdata image and completed boot. Its current host AVD data directory
is about 514 MiB. The host root filesystem had 8.7G available immediately after
cleanup and about 8.2G after H3 startup; `/data0` was not modified.

Starting H3 alongside the still-running GW initially filled the test host's
6G swap and reduced available RAM to about 67 MiB. H1 and H2 were then shut down
cleanly with `adb emu kill` (their AVD data was preserved). With only GW and H3
running, the host recovered to about 3.5 GiB available RAM and 2.6/6 GiB swap
used; `vmstat` showed near-zero continuing swap traffic. No disk cleanup beyond
the three listed inactive AVDs was performed.
